Winner Picks — Where There Is a Choice

When two tools compete for the same slot, I pick one. Here are the decisions with reasoning.

FluidVoice over Whisper (macOS dictation)

REPLACE

Verdict: FluidVoice wins on every metric that matters: on-device (zero latency), custom AI enhancement (better quality), native macOS (better UX). Whisper stays as web/Windows/Linux fallback — but for Mac users, FluidVoice is the primary dictation engine. Not a compromise — a platform-specific upgrade.

Voicebox over Kokoro (TTS engine)

REPLACE

Verdict: Kokoro was never deployed to production. Browser speechSynthesis is the live fallback and it sounds robotic. Voicebox is open source, on-device, high-quality neural TTS, built for real-time voice interaction. Replace Kokoro entirely — deploy Voicebox as the Voice Companion PWA TTS engine. Users will hear the difference immediately.

DesktopCommanderMCP over custom terminal code

REPLACE

Verdict: RHOBEAR agents currently use custom code for terminal + filesystem operations. DesktopCommanderMCP is the MCP standard — any MCP-compatible agent gets the same interface. Less code to maintain. Broader ecosystem compatibility. Replace, do not wrap.
