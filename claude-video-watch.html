Claude Video /watch - Let Claude Watch Any Video

Star 9,639 Python | bradautomates/claude-video | /plugin install watch@claude-video

What It Does

Gives Claude the ability to watch any video. Downloads via yt-dlp (YouTube, TikTok, X, Instagram, Loom, 300+ sites), extracts frames (scene-aware keyframes or full decode), pulls timestamped transcript (free captions or Whisper fallback), hands everything to Claude. Claude SEES the video AND HEARS the audio - not just reading a transcript.

Why This Changes the Research Agent

Right now the research agent pulls transcripts from YouTube. Transcripts miss 90% of what is on screen. When @TheNextNewThingAI shows a tool demo, the transcript says "this is amazing" but the FRAMES show the actual UI, the repo URL, the configuration. Claude Video lets the agent actually WATCH the demo - see the screenshots, read the UI text, catch visual details the transcript never names.

Key Features
