Social Media Director Stack

Assessment for building a director agent that plans, shoots, edits, and engages — at scale. July 2026.

The Vision

A director agent that takes your creative brief ("talk about X while walking here"), plans the shots, tells you what to film, then edits the footage through automated tools. No voiceover needed — these are walking/talking selfie-style videos. The agent directs YOU, then edits the result. Scale: hundreds of videos over time, not a one-off.

capcut-mate — The Editing Engine

Star 1,420 Python | Hommy-master/capcut-mate | Open-source

What It Actually Is

capcut-mate is an open-source automation layer on top of CapCut/Jianying. It is NOT its own video editor — it DRIVES CapCut through automation. Think of it as a robot that operates CapCut for you: creates drafts, adds clips, inserts effects, burns subtitles, exports the final video. You still need CapCut installed. You still need a CapCut account. But you never click the buttons — the agent does.

What It Can Do

Draft Management
Create, get, save CapCut drafts programmatically
Material Addition
Add video clips, audio, images, stickers, subtitles, effects, masks
Keyframe Control
Animation effects, text styles — precise control over motion
Cloud Rendering
Export final video — cloud rendering means your machine stays free
REST API
Standard API. Any agent can call it. Coze/n8n workflows supported.
Subtitle Burning
Auto-generate and burn subtitles into video — critical for social media

The Catch

Requires CapCut. capcut-mate is middleware — it sits between your agent and CapCut. You need:
1. CapCut/Jianying installed on the machine
2. A CapCut account (free tier works)
3. The capcut-mate server running locally

The agent calls capcut-mate API → capcut-mate drives CapCut → CapCut renders the video. This is not a standalone editor. If CapCut changes their API or ToS, this breaks.

Open-Source Alternative: VibeFrame

VibeFrame (vericontext/vibeframe) — AI-native video CLI. FFmpeg-based editing, storyboard pipelines, agent-friendly automation. No account needed. No proprietary software dependency. Does not have CapCut's polish or effects library, but it is fully open-source and cannot be rug-pulled. For a ground-floor build that will process hundreds of videos, VibeFrame is the safer foundation.

locoagent — The Engagement Engine

Star 1,031 TypeScript | LocoreMind/locoagent | MIT License

What It Actually Is

locoagent is a Claude Code fork rebuilt for social media. It drives a REAL Chrome browser via CDP (Chrome DevTools Protocol) using your actual login cookies. No API tokens. No headless fingerprint detection. It opens real X.com, real LinkedIn, real Reddit — and interacts the way a human would: scrolling, reading, liking, replying, following.

What It Does (NOT Posting)

Like posts
Finds relevant posts in your niche and likes them. Human-paced. Never spammy.
Write replies
Reads a post, drafts a genuine reply, posts it. 37 operation playbooks for X.com alone.
Follow users
Finds accounts in your niche. Follows them. Operation log prevents duplicates.
Operation Log
Cross-session deduplication. Never likes the same post twice. Never follows the same person twice. This is the feature that makes it safe for long-term use.
Multi-platform
X, LinkedIn, Reddit — concurrently. Isolated Chrome per platform.
Workflow Engine
Deterministic LLM-free pipelines for repetitive tasks. Agent supervises, engine executes.
Persona System
Define your voice. Agent stays in character across every reply.

Safety: Why It Will Not Get You Banned

Real browser. Real cookies. Real session. Platforms see a human using Chrome — because that is what is happening. No API tokens that trigger bot detection. No headless mode that leaves fingerprints. The operation log guarantees you never repeat an action (repetition is what triggers bans). Human-paced timing (it does not fire 100 likes in 10 seconds). This is the safest form of automation because it is indistinguishable from a person using a browser.

What It Does NOT Do

Does NOT post original content. Locoagent does likes, replies, and follows — ENGAGEMENT. It does not compose and publish original posts/tweets. This is exactly what you want: automated engagement to grow the account, manual posting for the actual content. The content stays human. The engagement scales.

The Full Stack: Director Agent Architecture

Pipeline

1. DIRECT: Agent plans the shoot — "film yourself walking down this street, say these 3 points, hold the phone at this angle"
2. SHOOT: You film on your phone. Raw footage.
3. REVIEW: Claude Video /watch analyzes the footage — "the lighting drops at 0:45, re-shoot that segment" or "takes 2 and 4 are good, use those"
4. EDIT: Agent drives capcut-mate (with CapCut) or VibeFrame (open-source) — assembles clips, adds subtitles, applies effects, renders final video
5. POST: YOU post manually. No automation on publishing. You review the final cut and hit post.
6. ENGAGE: locoagent handles likes, replies, follows — grows the account between posts

Build vs Buy

The Director Agent Must Be Built

No existing tool takes a creative brief and outputs a shot list with editing instructions. This is the orchestration layer — it is YOUR IP. The tools below it (editing, engagement, review) are all open-source and ready. The director is the glue. Building it means:

1. Custom Claude Code skill or standalone agent
2. Takes brief: topic, tone, location, duration
3. Outputs: shot list, talking points, editing instructions
4. Calls claude-video /watch for footage review
5. Calls capcut-mate or VibeFrame for editing
6. Hands you the final video for manual posting

Why Ground-Floor Build Is Correct

You are right — this should be built from the ground up. The tools exist as components. Nobody has wired them together into a director agent. Whoever builds this first owns the category. The editing tools (capcut-mate, VibeFrame) handle the heavy lifting. The engagement tool (locoagent) handles growth. The director is the unique piece — and it should be RHOBEAR.

What Is Missing

CapCut dependency. capcut-mate is the most polished editing option but ties you to CapCut. VibeFrame is fully open-source but less polished. Recommendation: start with VibeFrame as the editing backend. If you need CapCut-level effects later, add capcut-mate as an alternative renderer. The director agent should support both.
Shot planning intelligence. The director needs to understand framing, pacing, visual variety. This is not a tool problem — it is a prompt engineering problem. Claude can already do this if given the right system prompt ("you are a film director, plan shots that vary between wide, medium, and close-up...").
Multi-platform formatting. Vertical (TikTok/Reels) vs horizontal (YouTube). Different platforms need different aspect ratios. The editor needs to handle both from the same source footage.
