Verdict: Keep Piper. Watch Voicebox.

Piper wins where it matters: deployment, fine-tuning, and voices. 12 voices already trained on real audio, wired into Rho, running on-device via piper-wasm, and integrated with /api/tts. Voicebox has a newer architecture (Qwen3-TTS) and voice cloning — compelling features — but it would need to be fine-tuned on the same real audio, integrated into the piper-wasm pipeline, and wired into /api/tts. That is months of work to potentially get better raw quality.

Short-term: Piper stays. The 12 voices are proprietary assets — nobody else has them. Voicebox cannot match "Rho" or "Luna" without the same fine-tuning data.

Long-term: Monitor Voicebox. If Qwen3-TTS proves significantly better than VITS in blind A/B tests, consider fine-tuning Voicebox on the same real audio dataset. Voice cloning feature would let users create custom voices — a potential premium feature.

What to compare: Generate the same sentence with Piper (Rho) and Voicebox (best available voice). Blind A/B test. If Voicebox is noticeably better, it is worth the migration. If not — Piper has the deployment advantage.
